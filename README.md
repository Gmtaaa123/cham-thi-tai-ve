# Chấm Thi: tải bộ cài

Chương trình chấm phiếu trả lời trắc nghiệm (mẫu Phiếu TLTN THPT 2026) trên máy tính Windows.

## Tải về

**[⬇ Tải ChamThi-Setup.exe (bản mới nhất)](https://github.com/Gmtaaa123/cham-thi-tai-ve/releases/latest/download/ChamThi-Setup.exe)**

## Cài đặt

1. Mở file `ChamThi-Setup.exe` vừa tải.
2. Nếu Windows hiện "Windows protected your PC", bấm **More info** rồi **Run anyway**. Cảnh báo này xuất hiện vì bộ cài chưa có chữ ký số.
3. Bấm **Next** cho đến khi xong. Chương trình tự mở trình duyệt tại `http://127.0.0.1:5000`.
4. Lần đầu sử dụng, tạo tài khoản quản trị trên trang hiện ra.

Yêu cầu: Windows 10 hoặc 11 (64-bit). Không cần cài Python hay kết nối mạng.
